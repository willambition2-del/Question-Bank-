# بنك الأسئلة للثالث الثانوي — مشروع Flutter Frontend التفاعلي

تطبيق تعليمي كامل وجذاب مخصص لطلاب الصف الثالث الثانوي في اليمن لمذاكرة وحل الأسئلة والامتحانات الوزارية بطابع تفاعلي وبصري متميز، يعتمد كلياً على Frontend ولا يتطلب تهيئة قاعدة بيانات حقيقية.

---

## 🎨 دليل الهوية البصرية والتصميم
*   **لوحة الألوان الرسمية**:
    *   الأزرق الأساسي (Primary Blue): `#315BE8`
    *   التيل الثانوي (Secondary Teal): `#16C7B0`
    *   الذهبي المساعد (Gold Accent): `#F6C445`
    *   البرتقالي الدافئ (Warm Orange): `#FF9F43`
    *   الأحمر المرجاني (Error Coral): `#FF4D4D`
    *   *ملاحظة هامة: تم حظر وتجنب استخدام اللون البنفسجي أو درجاته في كامل شاشات التطبيق.*
*   **شخصية المستشار المساعد التفاعلي (`CharacterCompanion`)**:
    *   يدعم التطبيق شخصيتين محليتين: **وضاح** (بثوب تقليدي وجنبية وعمامة) و**بلقيس** (بحجاب وتصميم عربي تقليدي).
    *   تتفاعل الشخصية حركياً وبصرياً مع أداء الطالب (سؤال صحيح، خاطئ، تلميح، انتهاء الوقت).
    *   يدعم 3 مستويات للحركة (حركة كاملة، حركة مخففة، إيقاف الحركة) لتوفير شحن البطارية.

## 📁 هيكلية ملفات المشروع
تم بناء المشروع وتقسيمه معمارياً بشكل يسهل تطويره واستبدال البيانات التجريبية بـ Backend حقيقي لاحقاً:

```text
lib/
├── app/
│   ├── router/          # تهيئة GoRouter وإدارة التبويبات (TabIndexProvider)
│   └── theme/           # الألوان (Colors)، الخطوط (Cairo/Tajawal)، الظلال، والأحجام
├── core/
│   ├── models/          # نماذج الكيانات الدراسية والامتحانات والتحديات والأوسمة
│   ├── mock/            # قاعدة بيانات تجريبية مدمجة تحاكي تأخير الشبكة والـ Repositories
│   └── widgets/         # المكونات المشتركة: الأزرار، البطاقات، المساعد التفاعلي، الشريط السفلي
└── features/
    ├── auth/            # شاشات الدخول والتسجيل واختيار المساعد (وضاح أو بلقيس)
    ├── challenges/      # شاشات ومحرك محاكاة التحديات (1 ضد 1 مباشر، انتظار، لعب)
    ├── exam_models/     # استعراض النماذج الوزارية مع فلاتر السنة والمحافظة والمادة
    ├── home/            # الواجهة الرئيسية وتصميم الـ Shell والـ Tab Bar
    ├── leaderboard/     # لوحة المتصدرين وتكريم المراكز الثلاثة الأولى (منصة ذهبية وفضية وبرونزية)
    ├── mistakes/        # شاشة سجل الأخطاء مع إمكانية مراجعة التفاصيل وبدء اختبار أخطاء
    ├── profile/         # الملف الشخصي وإعدادات التخصيص والأوسمة
    ├── quiz/            # محرك اختبار الأسئلة، المؤقت التفاعلي، القلوب، المساعدات، والقطع القرائية
    ├── results/         # عرض تفاصيل أداء الاختبار ومشاركة النتيجة مع خطة المراجعة الذكية
    ├── saved_questions/ # الأسئلة المحفوظة للرجوع إليها لاحقاً مع فلاتر البحث
    ├── splash/          # شاشة البدء المؤقتة مع شعار التطبيق
    └── statistics/      # شاشة الإحصائيات بالرسوم البيانية (Line, Bar, Pie charts) باستخدام fl_chart
```

## 🛠️ محركات المحاكاة المحلية
1.  **آلة حالة الأسئلة (`QuizQuestionStatus`)**:
    *   تدير تدفق الاختبار: قراءة السؤال، التحقق من الإجابة، تلميحات المساعد، تبسيط الخيارات (استبعاد خيار)، وحفظ الأسئلة.
2.  **محاكي التحديات المباشرة (`ChallengeSimulationEngine`)**:
    *   البحث عن خصوم بمستويات ذكاء وسرعة مختلفة (مبتدئ، متوسط، متقدم، خبير).
    *   لعب تفاعلي 1 ضد 1 مع عرض حالة إجابات الخصم (يفكر، أجاب، انتهى الوقت) وتحديث درجاتهم حياً.

## 🚀 تشغيل وتجربة التطبيق

### 1. تثبيت التبعيات
تأكد من تنزيل وتثبيت كافة الحزم والتبعيات المرتبطة بـ Riverpod و GoRouter والرسوم البيانية وغيرها:
```bash
flutter pub get
```

### 2. تشغيل الاختبارات
للتحقق من سلامة تهيئة التطبيق وأكواد التوطين (Arabic RTL) وبناء شجرة مكونات Riverpod:
```bash
flutter test
```

### 3. تشغيل التطبيق محلياً
لتشغيل التطبيق على الهاتف المحمول أو المحاكي:
```bash
flutter run
```
