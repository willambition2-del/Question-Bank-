# Question import validation rules

MCQ requires text, mapped subject, at least two nonblank distinct options, and exactly one explicit correct option. True/false accepts only explicit صح/صواب/True or خطأ/False forms; ambiguous source answers are invalid. Missing lesson, unit mismatch, source review flag, or uncertain curriculum mapping forces REQUIRES_REVIEW. Missing passage/image is invalid when the row declares it. Unsupported question types are invalid. Invalid/review rows are never published or used by quizzes.
